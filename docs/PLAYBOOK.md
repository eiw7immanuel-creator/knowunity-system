# Playbook: how the Knowunity content team works

Short enough to read in five minutes, precise enough to remove every hand-off question. The short version lives inside the app under **How it works**, where the numbers follow your settings; the defaults are used here.

## The goal in numbers

| | |
|---|---|
| Posts per month | **60**, cross-posted to Instagram, TikTok and YouTube Shorts |
| Per day | **2** slots on every calendar day |
| Drops per month | **3**, one every ~10 days |
| Videos per drop | **20**, so 7+ clips at 3 variations each |
| Editor turnaround | **24 hours** from the moment a drop is sent |
| Review turnaround | **24 hours** from delivery |
| Buffer | keep **5 days** (10 videos) scheduled ahead |

**The one rule:** a drop is sent with a link and a brief, and the editor delivers within 24 hours. Creators approve within 24 hours. Nothing waits on a chat message; the board is the source of truth.

## Roles

- **Creators (Immanuel and Adam)** film, create the drop, review deliveries, and post on their rota days. Both platforms, both slots, ticked in the board.
- **Editor** starts the drop, cuts every clip into as many strong variations as the brief asks for, uploads to the drop's Drive folder, and logs the delivery with one line per video.
- **Everyone** keeps their own status current. If the board is right, nobody has to ask.

## How a drop flows

1. **Film.** Shoot a batch on a filming day. Aim for at least 7 usable clips so the editor can produce 20 videos.
2. **Upload.** Put the raw files in `Drops / YYYY-MM / Dnn / RAW` and set sharing so the editor can view.
3. **Send the drop.** In the app: *New drop* → Drive link, clip list, brief, target count. The deadline is set automatically. Copy the handoff message into the team chat.
4. **Edit.** The editor taps *Start editing*, works from the brief, exports to `Dnn / EDITS`, and names files after their code, e.g. `D07-C03-v2_hook-name.mp4`.
5. **Deliver.** *Log delivery* → paste the EDITS link and one title per line. Each line becomes a video card in *Delivered*. Prefix a line with `C3:` to link it to clip 3.
6. **Review.** A creator watches, then *Approve* or *Request changes* with a note. Approved videos land in *Ready to post*.
7. **Schedule.** *Auto-fill* the empty slots from Ready. Keep at least 5 days (10 videos) scheduled ahead.
8. **Post.** The day's poster opens *Today*, posts slot 1 and slot 2 on Instagram, TikTok and YouTube Shorts, and ticks all three boxes. The month counter moves.

## Drive structure and naming

```
Knowunity Content/
  Brand assets/            logos, fonts, music, caption templates
  Drops/
    2026-09/
      D07/
        RAW/               original files straight from the phone or camera
        EDITS/             D07-C01-v1_exam-trick.mp4
                           D07-C01-v2_exam-trick-subtitles.mp4
                           D07-C03-v1_pov-11pm.mp4
```

Codes are generated by the app: `D07` is the drop, `C03` the clip it came from, `v2` the variation. Keep the code at the start of every file name so anyone can find the source clip in seconds.

### Export spec

- 9:16 vertical, 1080 × 1920, H.264 MP4, 30 fps (60 fps only if filmed that way).
- Keep text inside the safe zone: away from the bottom 20 % and the right edge where platform UI sits.
- No platform watermark. Upload the same clean file to Instagram, TikTok and YouTube separately, never a re-download.
- Subtitles burned in for variations meant to work on mute.

## Cross-posting checklist

- Post the Instagram Reel first from the clean file, then upload the same file to TikTok and as a YouTube Short.
- Adjust the caption per platform (hashtags and hook line), keep the first line identical so performance is comparable.
- Use the same cover frame on both platforms.
- Tick Instagram, TikTok and YouTube in the board as soon as each one is live. All three ticked = posted.

## When something slips

- **Drop overdue:** the Today page shows it red. Ping the editor with the handoff message; if they are blocked, reassign the drop to another editor in *Edit details*.
- **Poster unavailable:** open that day in the Calendar and swap the poster. The swap shows a ring on the avatar so everyone can see it.
- **Empty slots ahead:** use *Auto-fill*. If Ready is empty, that is the signal to send the next drop early.
- **Behind pace:** the hero card shows how many posts per day are now needed. Add a third slot temporarily under *Team → Posts per day*.

## Weekly ten-minute review

- Pace vs target on the Today page.
- Buffer: at least 5 days scheduled.
- Any drop older than 24 h without delivery, any delivered video older than 24 h without a decision.
- Next filming day on the calendar, so the next drop lands before Ready runs dry.
